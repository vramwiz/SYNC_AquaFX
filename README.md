# 水面演出

波・流れ・波紋のある水面や、液体の表面に浮く油膜を描く AviUtl2 用フィルタープラグインです。素材なしの水面生成、入力画像の波による変形、ラーメンなどの画像への油膜合成に対応します。`SYNC_ParticleFX` の共通基盤を引き継ぎ、CPU で描画します。

| 項目 | 内容 |
| --- | --- |
| プロジェクト名 | SYNC_AquaFX |
| プラグイン名 | 水面演出 |
| グループ | SYNC |
| 対象 | Windows 64bit / AviUtl2 2.1.16 以降 |
| 開発環境 | Delphi 37.0 / Win64 |
| バージョン | v0.6.0 |

素材なしで水面を生成できます。CPU で波・流れ・波紋を合成し、疑似反射・ハイライト・簡易な泡を加えます。プリセットは同じ描画処理の形状・色・動き・質感を切り替えます。

## インストール・更新

1. AviUtl2 を終了します。
2. 配布ファイル `SYNC_AquaFX.zip` を展開します。
3. 中の `SYNC_AquaFX` フォルダーを AviUtl2 の `Plugin` フォルダーへコピーします。標準の配置先は `C:\ProgramData\aviutl2\Plugin\SYNC_AquaFX` です。
4. AviUtl2 を起動し、画像オブジェクトまたはフィルタオブジェクトへ「SYNC」グループの「水面演出」を追加します。

本体は `SYNC_AquaFX.auf2` の1つです。README・LICENSE・THIRD_PARTY_NOTICES.md・ThirdParty 内の SDK ライセンスも一緒に配置してください。更新も同じ場所へ上書きします。アンインストール時は AviUtl2 を終了し、同梱の5ファイルを削除します。

配布・ソースの公開先: [vramwiz/SYNC_AquaFX](https://github.com/vramwiz/SYNC_AquaFX)

## 使い方

- **素材なしで生成**：タイムラインへフィルタオブジェクトを置き、「SYNC」の「水面演出」を追加します。「背景あり」「海」を選び「設定」を押すと、シーンと同じサイズの水面を生成します。
- **既存のフィルタオブジェクト**：「水面演出」を追加し、「背景あり」で水面を生成できます。下層に画像がなくても表示します。
- **画像へ適用**：画像オブジェクトへ「水面演出」を追加します。「ユーザー画像」では入力画像を波で変形し、光沢を加えます。元画像の透明部分には描画しません。
- **ラーメン画像へ油を重ねる**：「画像に油膜」を選び、プリセット「油」で「設定」を押します。元画像の位置とアルファを保ち、油膜の縁と照りを重ねます。「円形・楕円形」と「座標・変形」でスープの位置へ合わせます。
- **コーヒーカップの液面を揺らす**：「画像に波」を選び、「コーヒー」で「設定」を押します。「円形・楕円形」と「座標・変形」でコーヒーの範囲へ合わせます。カップ・取っ手・背景と元画像のアルファを保ち、液面の反射を波で揺らします。
- **流れを渦にする**：「渦の強さ」を正にすると時計回り、負にすると反時計回りです。「渦の速さ」「渦の広がり」で調整できます。直線方向への流れを止める場合は「流速」を0にします。油膜にも使えます。水面生成にはプリセット「渦」も用意しています。
- **浴槽へ落水の波紋を重ねる**：「落水の波紋」で「設定」を押すと、水面の中心から波紋が繰り返し広がります。「波紋の散らばり」0が固定点、100が従来のランダム配置です。「波紋の縦横比」で横長の水面でも輪を円形へ補正できます。落ちる水そのものは描きません。浴槽画像を下のレイヤーへ置き、別の画像オブジェクトへ「背景あり」の水面を付けて重ねると、浴槽の縁を保てます。
- **効果だけを重ねる**：「背景なし」では背景色を描かず、ハイライトと泡を透明背景に描きます。下層画像の屈折変形は「ユーザー画像」で行います。

本体は `SYNC_AquaFX.auf2` の1つです。更新後は AviUtl2 を終了して再起動してください。

| 表示モード | 動作 |
| --- | --- |
| 背景あり | 液体色を下地として、水面・光沢・泡・油膜を生成する。 |
| ユーザー画像 | 入力画像を波で変形し、光沢や油膜を加える。 |
| 背景なし | 背景を透明にして、光沢・泡・油膜だけを描く。 |
| 画像に油膜 | 元画像の位置とアルファを保ち、油膜だけを重ねる。 |
| 画像に波 | 元画像を保ち、指定した液面内だけを波で変形・合成する。 |
| 画像に水面 | 元画像を保ち、生成した水面の色を指定範囲へ重ねる。排水後は元画像に戻る。 |

平面・長方形・円形／楕円形と、傾斜・水平回転・遠近感に対応します。「画像形状」は入力画像のアルファをマスクとして使い、画像とアルファ形状を一緒に投影します。画像のあるオブジェクトに適用してください。画像ファイルの直接指定は今後の対象です。

## プリセットとパラメータ

設定欄の最上段を「プリセット」リスト、その直下を「設定」ボタンにしています。通常の調整パラメータはその下に並びます。

1. 「プリセット」で用途を選びます。
2. 「設定」を押し、水面形状、液体色、波・流れ・波紋・粘度・光沢・泡・疑似3Dの初期値を一括反映します。
3. 反映された各パラメータを個別に調整します。

選択リストを変えるだけでは現在のパラメータは変わりません。表示モード・シードと「座標・変形」の全項目は「設定」を押しても維持します。

海、海岸、川、池、湖、水たまり、お風呂、プール、ラーメンスープ、味噌汁、牛乳、コーヒー、油、魔法液体、渦、落水の波紋、海岸の寄せ返し、栓を抜く、トイレの水を流すの19種類を用意しています。粘度は波と流れの速度、波紋の広がりと減衰へ反映します。

「渦」は中心ほど速く回る水面です。「渦の凹み」で中心を少し低く見せ、「渦の吸い込み」で中心へ向かう屈折と淡い濃淡を加えます。水面から浮いた白い輪は加えず、波紋の量と泡の量の初期値は0です。「渦中心X/Y」は入力画像の中心からのピクセル座標で、初期値0が画像中心です。水面全体の位置とは独立して指定できます。「設定」を押しても渦中心X/Yは維持します。渦の強さ0または速さ0で回転を止められます。

「画像に波」は透明度100・拡大率0、または波の強さ・波紋の量・油膜の量がすべて0の場合、元画像をそのまま返します。液面は自動認識しないため、カップの内側へ形状を合わせてください。

「画像の陰影」は「画像に波」での暗い陰影を調整します。牛乳など白い液体には15程度、黒っぽい帯を避けたい場合は0へ下げます。変形と明るいハイライトは保ちます。「牛乳」の初期値は15、「コーヒー」は100です。コーヒーは反射の動きを見やすくするため、波の強さ28・波の速度0.70・波紋45・ハイライト90を初期値にしています。

水系の8種類は「魔法液体」の波・粘度・光沢を基準に、流速や泡を用途ごとに調整しています。平面だけ波を3倍細かくする処理を除き、形状を変えても同じ基準の波を使います。

更新前のプロジェクトには以前の数値が保存されているため、再起動後にプリセットを選び直して「設定」を押すと新しい初期値になります。

## 栓を抜く

空の浴槽画像を下層へ置き、同じ画像の上層に水面演出を追加します。「背景あり」でプリセット「栓を抜く」を選び「設定」を押し、水面の長方形を浴槽へ合わせます。「渦中心X/Y」を画像内の排水口へ合わせると、その場所に凹みと渦を作り、水面が集まりながら減っていきます。

**適用先オブジェクト、または単独のフィルタオブジェクトの全長が排水時間です。** 先頭フレームを満水、最後のフレームを排水後として計算するので、タイムラインを長くするとゆっくり抜けます。途中からの再生と逆シークにも対応します。上層の水面が消えた後は、下層の空の浴槽が見えます。

「渦の凹み」「渦の吸い込み」は0～100、「排水の量」は0で排水なし、100で終端に水面が消えます。50なら一部の水を残します。「渦」は排水の量0、「栓を抜く」は100です。水位低下は平面の輪郭の後退で表現し、終盤は濃さを保った細い水の尾が栓へ流れ込みます。栓そのものの移動は描きません。

`Sample/bath_drain_preview.gif` は既存の浴槽画像へ重ねた8秒の排水サンプルです。画像の更新前から配置されている「渦」には以前の値が保存されているため、新しい初期値を使う場合はプリセット「渦」で「設定」を押してください。

水面形状「角丸の四角」と「角の丸み」（0～100）で、便器などの丸い角へ合わせられます。0は四角、100は円・楕円です。「栓を抜く」を設定した後で形状と丸みを選びます。従来の長方形の動きは維持します。

## トイレの水を流す（試作）

便器の内周から出る薄い水膜が、回りながら「渦中心X/Y」の排水口へ進みます。オブジェクトの全長が開始から排水終了までの時間です。「給水終了」は全長に対する止水時点（%）で、その後も内側へ進んだ水が排水口へ抜けます。「流水の量」は水膜の濃さ、「流水の幅」は細かな流れの筋の幅です。「角の丸み」と共通の座標・変形で便器の内側へ合わせ、回転は「渦の強さ」「渦の速さ」で調整します。

流水の初期量は100です。流れの動きを見やすくするため、水膜の厚みと淡い水色を強めています。薄くする場合は「流水の量」または全体の「透明度」で調整できます。

2オブジェクトのサンプルは、下側の空の便器画像に「栓を抜く」「画像に水面」「角丸の四角」で溜まり水を重ね、上側の同じ便器画像に「トイレの水を流す」「背景あり」で流水だけを生成します。上下の排水口座標を揃えます。「画像に水面」は水面外・元画像のアルファを保ち、終端や透明度100・拡大率0では元画像をそのまま返します。画像がない場合は透明になります。

`Sample/toilet_empty.png` は水を含まない生成画像、`Sample/toilet_flush_preview.gif` は本番AUF2の2層を合成した8秒の確認用GIFです。平面の演出であり、便器形状の自動認識や厳密な流体計算は行いません。

## 海岸の寄せ返し（試作）

「背景あり」でプリセット末尾の「海岸の寄せ返し」を選び、「設定」を押します。素材なしのフィルタオブジェクトから、平面の海水と白い泡を生成します。初期状態は画面上側が海、下側が透明な砂浜側です。下層へ砂浜の画像を置くと、浅瀬から背景が透けます。砂浜自体はプラグインで生成しません。

水際が前進して減速し、少し長い時間をかけて引きます。場所ごとの到達時刻と輪郭に差を付け、水が退いた砂浜側から泡と薄い濡れ色を徐々に残します。水面形状「海岸」で有効になり、従来の「海岸」プリセットの出力は維持します。

| 項目 | 動作 |
| --- | --- |
| 波の到達幅 | 水際が前後する幅。0で前後の移動を止める。 |
| 寄せ返しの周期 | 1往復の秒数。初期値は6秒。 |
| 水際の不規則さ | 岸に沿った凹凸と到達時刻のばらつき。 |
| 海水の不透明度 | 海水の濃さ。泡の白さは維持し、0では泡だけになる。 |
| 泡の残り | 引いた後に残る泡と濡れ色の持続。泡そのものの量は「泡の量」で調整。 |

水際の位置・向き・大きさは「座標・変形」で調整できます。水と泡をまとめて薄くする場合は従来の「透明度」を使います。「背景なし」では泡だけを出力します。写真の海岸線の自動認識や任意形状への追従は行いません。

`Sample/shore_sand_preview.gif` は本番AUF2の72フレームを固定の砂浜へ重ねた6秒の確認用アニメーションです。`shore_alpha_preview.gif` は同じ出力を市松へ重ねた透過確認です。12fpsへ間引いたGIFで、AviUtl2の再生性能を示すものではありません。

## 浮いている油

「油」は黄色い下地に、透けた黄金色の油膜が分かれて浮くプリセットです。膜はゆっくり流れ、波に沿って形を変えます。膜の縁の陰と暖かい白の照りで、黄色同士でも油の輪郭が見えるようにしています。

「表面の油」で次を調整できます。水やスープ、ユーザー画像にも使用できます。

| 項目 | 動作 |
| --- | --- |
| 油膜の量 | 0で無効。増やすと膜が覆う面積が増える。 |
| 油膜サイズ | 大きくすると膜のまとまりが大きくなる。 |
| 油膜光沢 | 縁の反射と暖色の照りを調整。 |
| 油膜色 | 下地の「液体色」と独立した膜の色。 |

「背景なし」では透明背景に油膜と光沢を描き、「ユーザー画像」では入力画像のアルファ内へ重ねます。プリセットの「設定」を押すと油膜の値も切り替え、水系のプリセットへ戻すと油膜は0になります。

ラーメンなどの写真には「画像に油膜」を使います。薄い膜色・縁の陰・照りを合成し、麺や具材の細部を残します。座標・拡縮・傾斜は油膜の範囲へ適用し、元画像は移動しません。透明度100・拡大率0・油膜の量0では元画像をそのまま返します。具材を自動判別する機能はないため、器の内側へ形状を合わせてください。

## 座標と傾斜

「座標・変形」には入力プラグインの標準描画項目を参考にした調整を用意しています。フィルタオブジェクトでも、水面自体の位置や大きさを調整できます。

| 項目 | 初期値と動作 |
| --- | --- |
| X / Y / Z | 0。Xは右、Yは下、Zは奥が正。単位はピクセル。 |
| 中心X / 中心Y / 中心Z | 0。回転・拡縮の中心をピクセル単位で指定。 |
| X軸回転 / Y軸回転 / Z軸回転 | 0度。Z軸回転の正値は画面上で時計回り。 |
| 拡大率 | 100%。0で水面・油膜を非表示。 |
| 縦横比 | 0。正値は横方向、負値は縦方向へ広げる。 |
| 透明度 | 0%。100で水面・油膜が完全透明。画像に油膜では元画像を保持。 |

X/Y/Z・中心・軸回転・透明度は0.01刻みの小数2桁、拡大率・縦横比は0.001刻みの小数3桁です。

「3D傾斜角度」は -89～89度です。0度は正面から見た状態、正値は上側が奥、負値は下側が奥になります。X軸回転はこの傾斜に加算します。「遠近感」0は平行投影のため、Zによる見かけの大きさの変化はありません。

形状が「平面」の場合は画面外へ連続する無限の水面です。枠や外周の位置・大きさを調整する場合は「長方形」または「円形・楕円形」を選びます。移動・回転した水面と画像は元の出力範囲でクリップします。

v0.3.0で傾斜の透視方向を修正したため、以前の正値と見た目が変わります。反対方向へ倒したい場合は負値を指定してください。

## 描画範囲・制限

描画は時刻・シード・設定から決まり、途中からの再生や逆シークでも同じ入力から同じ結果を返します。出力サイズは入力画像、または素材なしのフィルタオブジェクトではシーンのサイズです。幅・高さは各8,192ピクセル、総画素数は16,777,216を上限とします。高解像度では CPU の処理時間が増えます。

波・反射・泡は疑似表現です。従来の「海岸」は共通の波と簡易泡によるプリセットです。専用の平面の波打ち際は「海岸の寄せ返し」で試作しています。境界反射、落下する水、色の広がりは未実装です。人物や具材との当たり判定・自動判別、画像ファイルの直接指定は行いません。

開発仕様と今後の対象は [SYNC_AquaFX 開発指示書](docs/SPECIFICATION.md) に記載しています。

## ビルド

ビルド方法とコメント・文字コードの作業規則は [note.md](note.md) に記録しています。

Delphi で `SYNC_AquaFX.dproj` を開き、Win64 の Debug または Release をビルドします。

コピー元のコンパイラー設定・デバッガーのホスト設定・ビルドイベントを引き継いでいます。プロジェクト名、GUID、参照ユニット、出力先を本プロジェクトに合わせています。

DLL から AUF2 へのコピーと不要ファイル削除は、IDE で改行が変換されても処理が省略されないよう一行のコマンドにしています。コピー成功時のみ DLL を削除します。

- AUF2 出力先（Debug / Release 共通）: `C:\ProgramData\aviutl2\Plugin\SYNC_AquaFX\SYNC_AquaFX.auf2`
- DCU 出力先: `Win64\Debug\DCU` / `Win64\Release\DCU`
- ビルド後に DLL を AUF2 へコピーし、DLL を削除します。Release では RSM も削除します。
- Debug / Release は同じ AUF2 を上書きするため、配布前に Release をビルドしてください。

PowerShell からビルドする場合:

```powershell
cmd /c 'call "C:\Program Files (x86)\Embarcadero\Studio\37.0\bin\rsvars.bat" && msbuild SYNC_AquaFX.dproj /t:Build /p:Config=Debug /p:Platform=Win64'
cmd /c 'call "C:\Program Files (x86)\Embarcadero\Studio\37.0\bin\rsvars.bat" && msbuild SYNC_AquaFX.dproj /t:Build /p:Config=Release /p:Platform=Win64'
```

## 確認

描画の回帰テストは `Tests/run_tests.ps1` で実行します。素材なしの204×204生成、本番AUF2の描画コールバック、19プリセット、逆シーク、入力アルファ、画像に波の範囲外保持、渦の方向と勾配、海岸の折返し、排水と流水の時間追従・中心移動・終端、角丸、画像に水面の原画像保持を確認します。検査用EXEは本番AUF2を読み込み、別のプラグインは作りません。確認画像は `Win64/Verification/Images` に出力します。

## 構成

- `SYNC_AquaFX.dpr`: DLL の公開関数、対応バージョンの確認。
- `Source/Plugin/Filter/SYNC_AquaFX_FilterPlugin.pas`: 名前・グループの登録、映像処理コールバック。
- `Source/Plugin/Filter/AquaFX_Parameters.pas`: プリセットを先頭にした標準項目の登録と設定ボタン。
- `Source/Common/AquaFX_Settings.pas`: 共通パラメータと19種類のプリセット初期値。
- `Source/Common/AquaFX_Renderer.pas`: 時刻から直接計算する CPU 水面描画と画像変形。
- `Source/Common/AquaFX_Projection.pas`: 符号付き傾斜、位置・中心・拡縮・3軸回転の共通投影。
- `Source/Common/AquaFX_OilSurface.pas`: 下地と分離した浮遊油膜の模様・縁・光沢。
- `Source/Common/AquaFX_Flow.pas`: 波・油膜へ加える、時刻から直接計算する渦の移流と勾配。
- `Source/Common/AquaFX_VortexSurface.pas`: 渦の凹み、中心へ向かう筋、タイムラインの全長に合わせた排水。
- `Source/Common/AquaFX_SurfaceShape.pas`: 角丸の水面と流水で共用する輪郭。
- `Source/Common/AquaFX_Flush.pas`: 内周から排水口へ進む薄い水膜と給水時間。
- `Source/Common/AquaFX_Shore.pas`: 平面の水際、透ける浅瀬、引いた後に残る泡。
- `Source/Common/AquaFX_Profiling.pas`: Debug専用の工程別CSVログ。
- `Source/Lib/`: コピー元から引き継いだ SDK 型定義とフィルターテーブル登録処理。
- `docs/SPECIFICATION.md`: 水面演出の開発仕様全文。
- `setup/`: 配布 ZIP 作成バッチ、README、カタログ JSON、生成 ZIP。

参考元のパーティクル計算・描画、実験用 EXE、サンプル画像は引き継いでいません。[setup/README.md](setup/README.md) は配布 ZIP に収録する利用者向けの説明書です。

## 配布 ZIP の作成

Win64 Release をビルドした後、次を実行します。

```powershell
.\setup\make_release_zip.bat
```

既定では `%ProgramData%\aviutl2\Plugin\SYNC_AquaFX\SYNC_AquaFX.auf2` を梱包し、`setup/SYNC_AquaFX.zip` を作成します。`xxhsum.exe` は `Win64/Dependencies/xxHash-0.8.4` または PATH へ用意します。引数で別の本体フォルダーやハッシュ計算ツールも指定できます。

```powershell
.\setup\make_release_zip.bat -ReleaseDirectory 'V:\DelphiProg\SYNC_AquaFX\Win64\BuildCheck\Release'
.\setup\make_release_zip.ps1 -XxhsumPath 'C:\Tools\xxhsum.exe'
```

カタログ JSON 末尾の `XXH3_128` は、ZIP へ格納する AUF2 本体から自動更新します。README やライセンスだけの変更でも ZIP は再生成しますが、AUF2 が同一なら JSON のハッシュ値は維持します。スクリプトはビルドやネットワーク公開を行いません。梱包手順の詳細は [note.md](note.md) を参照してください。
