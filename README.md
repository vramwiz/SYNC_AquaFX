# 水面演出

波・流れ・波紋のある水面や、液体の表面に浮く油膜を描く AviUtl2 用フィルタープラグインです。素材なしの水面生成、入力画像の波による変形、油膜の合成、雨や雪の演出に対応します。

| 項目 | 内容 |
| --- | --- |
| プロジェクト名 | SYNC_AquaFX |
| プラグイン名 | 水面演出 |
| グループ | SYNC |
| 対象 | Windows 64bit / AviUtl2 2.1.16 以降 |
| 公開バージョン | v1.0.2 |

素材なしで水面を生成できます。CPU で波・流れ・波紋を合成し、疑似反射・ハイライト・簡易な泡を加えます。プリセットは同じ描画処理の形状・色・動き・質感を切り替えます。

## インストール・更新

1. AviUtl2 を終了します。
2. 配布ファイル `SYNC_AquaFX.zip` を展開します。
3. 中の `SYNC_AquaFX` フォルダーを AviUtl2 の `Plugin` フォルダーへコピーします。標準の配置先は `C:\ProgramData\aviutl2\Plugin\SYNC_AquaFX` です。
4. AviUtl2 を起動し、画像オブジェクトまたはフィルタオブジェクトへ「SYNC」グループの「水面演出」を追加します。

本体は `SYNC_AquaFX.auf2` の1つです。README・LICENSE・THIRD_PARTY_NOTICES.md・ThirdParty 内の SDK ライセンスも一緒に配置してください。更新も同じ場所へ上書きします。アンインストール時は AviUtl2 を終了し、同梱の5ファイルを削除します。

配布・ソースの公開先: [vramwiz/SYNC_AquaFX](https://github.com/vramwiz/SYNC_AquaFX)

## 使い方

- **素材なしで生成**：フィルタオブジェクトへ「SYNC」の「水面演出」を追加すると、初期の「背景」のまま内蔵の水面画像を生成します。液体色と波は設定欄で調整できます。
- **画像へ適用**：画像オブジェクトへ「水面演出」を追加し、表示モードを「なし」にすると、指定した液面に波・光沢・液体色を加えます。拡大率や位置で液面の範囲を調整でき、元画像の位置とアルファを保ちます。
- **ラーメン画像へ油を重ねる**：表示モードを「なし」にし、プリセット「油」で「設定」を押します。元画像の位置とアルファを保ち、油膜の縁と照りを重ねます。「円形・楕円形」と「座標・変形」でスープの位置へ合わせます。
- **コーヒーカップの液面を揺らす**：表示モードを「なし」にし、「コーヒー」で「設定」を押します。「円形・楕円形」と「座標・変形」でコーヒーの範囲へ合わせます。カップ・取っ手・背景と元画像のアルファを保ち、液面の反射を波で揺らします。
- **流れを渦にする**：「渦の強さ」を正にすると時計回り、負にすると反時計回りです。「渦の速さ」「渦の広がり」で調整できます。直線方向への流れを止める場合は「流速」を0にします。油膜にも使えます。水面生成にはプリセット「渦」も用意しています。
- **浴槽へ落水の波紋を重ねる**：「落水の波紋」で「設定」を押すと、水面の中心から波紋が繰り返し広がります。「波紋の散らばり」0が固定点、100が従来のランダム配置です。「波紋の縦横比」で横長の水面でも輪を円形へ補正できます。落ちる水そのものは描きません。浴槽画像を下のレイヤーへ置き、別の画像オブジェクトへ「背景」の水面を付けて重ねると、浴槽の縁を保てます。
- **効果だけを重ねる**：「エフェクト」はハイライトと泡などを元画像に重ねます。素材なしで単体配置すると、透明背景へ効果だけを描きます。画像の屈折変形は「なし」で行います。

本体は `SYNC_AquaFX.auf2` の1つです。更新後は AviUtl2 を終了して再起動してください。

| 表示モード | 動作 |
| --- | --- |
| 背景（初期値） | 内蔵の水面画像を表示する。液体色を下地に、形状や波の設定を反映する。 |
| なし | 元画像の模様を活かし、指定範囲へ選んだ効果を合成する。 |
| エフェクト | 光沢・泡・油膜などを元画像に重ねる。素材なしでは透明背景に効果だけを描く。 |

「設定」はプリセットに合わせて、「水面」の「水面色を重ねる」、「波」の「波表示」、「表面の油」の「油膜表示」も切り替えます。各チェックは手動でも変更できます。「水面色を重ねる」は「なし」で元画像に適用する色を切り替えます。

平面・長方形・円形／楕円形と、傾斜・水平回転・遠近感に対応します。「なし」で「画像形状」を選ぶと、入力画像とそのアルファ形状を一緒に投影します。素材なしで使う場合は「背景」を選ぶと内蔵の水面画像を生成します。旧「画像に波」「画像に油膜」「画像に水面」で保存した箇所は、表示モードを「なし」にし、それぞれ「波表示」「油膜表示」「水面色を重ねる」だけをオンにします。

## プリセットとパラメータ

設定欄の最上段を「プリセット」リスト、その直下を「設定」ボタンにしています。通常の調整パラメータはその下に並びます。

1. 「プリセット」で用途を選びます。
2. 「設定」を押し、水面形状、液体色、波・流れ・波紋・粘度・光沢・泡・疑似3Dの初期値を一括反映します。
3. 反映された各パラメータを個別に調整します。

選択リストを変えるだけでは現在のパラメータは変わりません。表示モード・シードと「座標・変形」の全項目は「設定」を押しても維持します。

海、海岸、川、池、湖、水たまり、お風呂、プール、ラーメンスープ、味噌汁、牛乳、コーヒー、油、魔法液体、渦、落水の波紋、海岸の寄せ返し、栓を抜く、トイレの水を流す、雨、雪、浅いプールの22種類を用意しています。粘度は波と流れの速度、波紋の広がりと減衰へ反映します。

「渦」は中心ほど速く回る水面です。「渦の凹み」で中心を少し低く見せ、「渦の吸い込み」で中心へ向かう屈折と淡い濃淡を加えます。水面から浮いた白い輪は加えず、波紋の量と泡の量の初期値は0です。「渦中心X/Y」は入力画像の中心からのピクセル座標で、初期値0が画像中心です。水面全体の位置とは独立して指定できます。「設定」を押しても渦中心X/Yは維持します。渦の強さ0または速さ0で回転を止められます。

「なし」で全部の表示チェックを外した場合、透明度100、または拡大率0の場合は元画像をそのまま返します。液面は自動認識しないため、カップの内側へ形状を合わせてください。

「画像の陰影」は「なし」で波を合成するときの暗い陰影を調整します。牛乳など白い液体には15程度、黒っぽい帯を避けたい場合は0へ下げます。変形と明るいハイライトは保ちます。「牛乳」の初期値は15、「コーヒー」は100です。コーヒーは反射の動きを見やすくするため、波の強さ28・波の速度0.70・波紋45・ハイライト90を初期値にしています。

水系の8種類は「魔法液体」の波・粘度・光沢を基準に、流速や泡を用途ごとに調整しています。

更新前のプロジェクトには以前の数値が保存されているため、再起動後にプリセットを選び直して「設定」を押すと新しい初期値になります。

## 浅いプール（試作）

「浅いプール」を選び、「設定」を押します。表示モードは「背景」と「エフェクト」に対応します。「水面の立体感」の「波の高さ」「水深」「水底の光」「気泡の量」で、波に沿って動く模様、水底の光、浮上して弾ける気泡を調整できます。「水深」0では水底の光と気泡が消えます。従来のプリセットでは4項目とも0です。

映像に光と気泡だけを重ねる場合は、その上に素材なしのフィルタオブジェクトを置き、表示モードを「エフェクト」にします。素材なしでは水面演出の「3D傾斜角度」で向きを調整します。標準描画で試す場合は、不透明な画像オブジェクトに水面演出を追加し、水面演出の傾斜を0°のまま、標準描画のX軸回転またはY軸回転を動かします。水面の輪郭は画像のアルファ内に収まり、模様・気泡・水底の光がそれぞれの高さに応じてずれます。

## 雨・雪

映像の上にフィルタオブジェクトを置き、「水面演出」を追加します。表示モードを「エフェクト」にし、プリセット「雨」または「雪」を選んで「設定」を押します。

- **雨**は雨筋と着地の飛沫を描きます。「雨の水たまり」は初期値35で、地面に沿った小さな水たまりと着水の波紋が出ます。0にすると雨筋と着地の飛沫だけになります。水たまりの色は「液体色」で調整できます。
- **雪**は大きさや速さの異なる雪片が揺れながら落ちます。積雪の表現はありません。

「3D傾斜角度」と「遠近感」で背景の地面に合わせます。傾斜0°は真上から見た平面で、雨・雪の初期値58°は斜めから地面を見下ろす角度です。「雨・雪の量」0で消え、「雨・雪の速さ」100が標準、0で静止します。「風の強さ」は正で右向き、負で左向きです。

画像オブジェクトに直接重ねる場合は、表示モード「エフェクト」で画像の位置とアルファを保って合成します。

## 栓を抜く

空の浴槽画像を下層へ置き、同じ画像の上層に水面演出を追加します。「背景」でプリセット「栓を抜く」を選び「設定」を押し、水面の長方形を浴槽へ合わせます。「渦中心X/Y」を画像内の排水口へ合わせると、その場所に凹みと渦を作り、水面が集まりながら減っていきます。

**適用先オブジェクト、または単独のフィルタオブジェクトの全長が排水時間です。** 先頭フレームを満水、最後のフレームを排水後として計算するので、タイムラインを長くするとゆっくり抜けます。途中からの再生と逆シークにも対応します。上層の水面が消えた後は、下層の空の浴槽が見えます。

「渦の凹み」「渦の吸い込み」は0～100、「排水の量」は0で排水なし、100で終端に水面が消えます。50なら一部の水を残します。「渦」は排水の量0、「栓を抜く」は100です。水位低下は平面の輪郭の後退で表現し、終盤は濃さを保った細い水の尾が栓へ流れ込みます。栓そのものの移動は描きません。

`Sample/bath_drain_preview.gif` は既存の浴槽画像へ重ねた8秒の排水サンプルです。画像の更新前から配置されている「渦」には以前の値が保存されているため、新しい初期値を使う場合はプリセット「渦」で「設定」を押してください。

水面形状「角丸の四角」と「角の丸み」（0～100）で、便器などの丸い角へ合わせられます。0は四角、100は円・楕円です。「栓を抜く」を設定した後で形状と丸みを選びます。従来の長方形の動きは維持します。

## トイレの水を流す（試作）

便器の内周から出る薄い水膜が、回りながら「渦中心X/Y」の排水口へ進みます。オブジェクトの全長が開始から排水終了までの時間です。「給水終了」は全長に対する止水時点（%）で、その後も内側へ進んだ水が排水口へ抜けます。「流水の量」は水膜の濃さ、「流水の幅」は細かな流れの筋の幅です。「角の丸み」と共通の座標・変形で便器の内側へ合わせ、回転は「渦の強さ」「渦の速さ」で調整します。

流水の初期量は100です。流れの動きを見やすくするため、水膜の厚みと淡い水色を強めています。薄くする場合は「流水の量」または全体の「透明度」で調整できます。

2オブジェクトのサンプルは、下側の空の便器画像に表示モード「なし」でプリセット「栓を抜く」を適用し、「角丸の四角」で溜まり水を重ね、上側の同じ便器画像に「トイレの水を流す」「背景」で流水だけを生成します。上下の排水口座標を揃えます。「水面色を重ねる」だけをオンにすると、水面外と元画像のアルファを保ち、排水後は元画像に戻ります。画像がない場合は透明になります。

`Sample/toilet_empty.png` は水を含まない生成画像、`Sample/toilet_flush_preview.gif` は本番AUF2の2層を合成した8秒の確認用GIFです。平面の演出であり、便器形状の自動認識や厳密な流体計算は行いません。

## 海岸の寄せ返し（試作）

プリセット「海岸の寄せ返し」を選び、「設定」を押します。砂浜の画像オブジェクトでは「なし」で、元の砂の模様に海水の色と白い泡を重ねます。素材なしのフィルタオブジェクトでは、画面上側に海水と泡を生成し、下側が透明になります。下層へ砂浜の画像を置くと、浅瀬から背景が透けます。

水際が前進して減速し、少し長い時間をかけて引きます。場所ごとの到達時刻と輪郭に差を付け、水が退いた砂浜側から泡と薄い濡れ色を徐々に残します。水面形状「海岸」で有効になり、従来の「海岸」プリセットの出力は維持します。

| 項目 | 動作 |
| --- | --- |
| 波の到達幅 | 水際が前後する幅。0で前後の移動を止める。 |
| 寄せ返しの周期 | 1往復の秒数。初期値は6秒。 |
| 水際の不規則さ | 岸に沿った凹凸と到達時刻のばらつき。 |
| 海水の不透明度 | 海水の濃さ。泡の白さは維持し、0では泡だけになる。 |
| 泡の残り | 引いた後に残る泡と濡れ色の持続。泡そのものの量は「泡の量」で調整。 |

水際の位置・向き・大きさは「座標・変形」で調整できます。水と泡をまとめて薄くする場合は従来の「透明度」を使います。「エフェクト」では泡を元画像に重ねます。素材なしでは透明背景に泡を描きます。写真の海岸線の自動認識や任意形状への追従は行いません。

`Sample/shore_sand_preview.gif` は本番AUF2の72フレームを固定の砂浜へ重ねた6秒の確認用アニメーションです。`shore_alpha_preview.gif` は同じ出力を市松へ重ねた透過確認です。12fpsへ間引いたGIFで、AviUtl2の再生性能を示すものではありません。

## 浮いている油

「油」は黄色い下地に、透けた黄金色の油膜が分かれて浮くプリセットです。膜はゆっくり流れ、波に沿って形を変えます。膜の縁の陰と暖かい白の照りで、黄色同士でも油の輪郭が見えるようにしています。

「表面の油」で次を調整できます。水やスープ、ユーザー画像にも使用できます。

| 項目 | 動作 |
| --- | --- |
| 油膜の量 | 0で無効。増やすと膜が覆う面積が増える。 |
| 油膜サイズ | 大きくすると膜のまとまりが大きくなる。 |
| 油膜光沢 | 縁の反射と暖色の照りを調整。 |
| 油膜色 | 下地の「液体色」と独立した膜の色。 |

「エフェクト」では油膜と光沢を重ねます。素材なしの場合は透明背景へ描きます。プリセットの「設定」を押すと油膜の値も切り替え、水系のプリセットへ戻すと油膜は0になります。

ラーメンなどの写真には表示モード「なし」とプリセット「油」を使います。薄い膜色・縁の陰・照りを合成し、麺や具材の細部を残します。座標・拡縮・傾斜は油膜の範囲へ適用し、元画像は移動しません。透明度100・拡大率0・油膜の量0では元画像をそのまま返します。具材を自動判別する機能はないため、器の内側へ形状を合わせてください。

## 座標と傾斜

「座標・変形」で水面自体の位置・大きさ・回転・透明度を調整できます。

| 項目 | 初期値と動作 |
| --- | --- |
| X / Y / Z | 0。Xは右、Yは下、Zは奥が正。単位はピクセル。 |
| 中心X / 中心Y / 中心Z | 0。回転・拡縮の中心をピクセル単位で指定。 |
| X軸回転 / Y軸回転 / Z軸回転 | 0度。Z軸回転の正値は画面上で時計回り。 |
| 拡大率 | 初期値100%。水面の基準寸法を調整し、0で水面を非表示。 |
| 縦横比 | -100～+100、初期値0。正の値は高さ、負の値は幅を縮める。+80なら幅を保って高さが20%になり、±100では水面が消える。 |
| 透明度 | 0%。100で水面・油膜が完全透明。「なし」では元画像を保持。 |

X/Y/Z・中心・軸回転・透明度は0.01刻みの小数2桁、拡大率・縦横比は0.001刻みの小数3桁です。

長方形を川のように細長くするには、拡大率で長辺の長さを決め、縦横比で短辺を絞ります。旧版で縦横比を調整した水面は、拡大率と縦横比を合わせ直してください。たとえば回転中心が初期値の水面では、旧版の拡大率68%・縦横比+100は、拡大率136%・縦横比+50に相当します。

「3D傾斜角度」は -89～89度です。0度は正面から見た状態、正値は上側が奥、負値は下側が奥になります。X軸回転はこの傾斜に加算します。「遠近感」0は平行投影のため、Zによる見かけの大きさの変化はありません。

形状が「平面」の場合は画面外へ連続する無限の水面です。枠や外周の位置・大きさを調整する場合は「長方形」または「円形・楕円形」を選びます。移動・回転した水面と画像は元の出力範囲でクリップします。

## 描画範囲・制限

描画は時刻・シード・設定から決まり、途中からの再生や逆シークでも同じ入力から同じ結果を返します。出力サイズは入力画像、または素材なしのフィルタオブジェクトではシーンのサイズです。幅・高さは各8,192ピクセル、総画素数は16,777,216を上限とします。高解像度では CPU の処理時間が増えます。

波・反射・泡は疑似表現です。従来の「海岸」は共通の波と簡易泡によるプリセットです。専用の平面の波打ち際は「海岸の寄せ返し」で試作しています。境界反射、落下する水、色の広がりは未実装です。人物や具材との当たり判定・自動判別、画像ファイルの直接指定は行いません。
