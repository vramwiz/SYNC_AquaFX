# 水面演出

波・流れ・波紋のある水面や、液体表面に浮く油膜を描く AviUtl2 用フィルタープラグインです。Windows 64bit / AviUtl2 2.1.16 以降を対象とします。プロジェクト名は SYNC_AquaFX、バージョンは v1.0.0 です。

## インストール・更新

1. AviUtl2 を終了します。
2. `SYNC_AquaFX.zip` を展開し、中の `SYNC_AquaFX` フォルダーを AviUtl2 の `Plugin` フォルダーへコピーします。標準の配置先は `C:\ProgramData\aviutl2\Plugin\SYNC_AquaFX` です。
3. AviUtl2 を起動し、画像オブジェクトまたはフィルタオブジェクトへ「SYNC」グループの「水面演出」を追加します。

更新も同じ場所へ上書きします。配布内容は次の5ファイルです。本体の AUF2 と一緒に README・ライセンス類も配置してください。

```text
SYNC_AquaFX/
  SYNC_AquaFX.auf2
  README.md
  LICENSE
  THIRD_PARTY_NOTICES.md
  ThirdParty/
    LICENSE.AviUtl2-SDK.txt
```

アンインストール時は AviUtl2 を終了し、上記5ファイルを削除します。

## プリセットと使い方

1. 設定欄の一番上の「プリセット」で用途を選びます。
2. その直下の「設定」を押すと、下の各パラメータへ初期値を一括反映します。リストを選ぶだけでは値は変わりません。
3. 波・流れ・波紋・粘度・反射・泡・油膜などを個別に調整します。

海、海岸、川、池、湖、水たまり、お風呂、プール、ラーメンスープ、味噌汁、牛乳、コーヒー、油、魔法液体の14種類があります。水系8種類は「魔法液体」の波・光沢を基準に調整しています。

「設定」は各グループ先頭の表示チェックを切り替え、表示モード・シード・「座標・変形」を保ちます。更新前の数値は保存済みのプロジェクトに残るため、新しい初期値を使う場合はプリセットを選び直して「設定」を押してください。

| 表示モード | 用途 |
| --- | --- |
| 背景（初期値） | 内蔵の水面画像を表示する。 |
| なし | 元画像の模様を活かして、選んだ効果を液面へ合成する。 |
| エフェクト | 光沢・泡・油膜などを元画像に重ねる。素材なしでは透明背景に効果だけを描く。 |

コーヒーなどの写真に適用するときは、「円形・楕円形」と「座標・変形」で液面へ合わせます。拡大率は液面の範囲だけに適用され、元画像の位置とアルファは保たれます。「なし」でプリセット「コーヒー」を適用すると、「波表示」だけがオンになり、元の色で波を描きます。

素材なしの場合はタイムラインのフィルタオブジェクトへ「水面演出」を追加します。初期の「背景」のまま、シーンと同じサイズの水面画像を生成します。

## 浮いている油・ラーメンへの合成

「油」は黄色い下地の上に、透けた黄金色の油膜が分かれて浮き、ゆっくり動くプリセットです。縁の陰と暖色の白い照りで膜の輪郭を出します。

| 項目 | 動作 |
| --- | --- |
| 油膜の量 | 膜が覆う面積。0で無効。 |
| 油膜サイズ | 大きくすると膜のまとまりが大きくなる。 |
| 油膜光沢 | 縁の反射と暖色の照り。 |
| 油膜色 | 下地の「液体色」と独立した膜の色。 |

ラーメンの写真などには、画像オブジェクトで表示モードを「なし」にし、プリセット「油」の「設定」を押します。「油膜表示」だけがオンになります。「円形・楕円形」と「座標・変形」でスープの位置へ合わせてください。元画像を動かさず、麺や具材の細部を残して油膜を合成します。具材の自動判別は行いません。

「なし」で油膜だけを重ねる場合は、透明度100・拡大率0・油膜の量0で元画像をそのまま返します。水系プリセットへ「設定」で切り替えると、油膜の量は0へ戻ります。

## 座標と傾斜

「座標・変形」で X/Y/Z、中心X/Y/Z、X/Y/Z軸回転、拡大率、縦横比、透明度を調整できます。Xは右、Yは下、Zは奥が正です。初期値は座標・回転・縦横比・透明度が0、拡大率が100%です。

X/Y/Z・中心・軸回転・透明度は0.01刻み、拡大率・縦横比は0.001刻みです。縦横比は -100～+100 で、正値は高さ、負値は幅だけを縮め、±100で水面が消えます。細長い水面は拡大率で長辺を決め、縦横比で短辺を絞ります。旧版で縦横比を調整した水面は、拡大率と縦横比を合わせ直してください。「3D傾斜角度」は -89～89度で、正値は上側が奥、負値は下側が奥になります。X軸回転は傾斜へ加算します。「遠近感」0では Z による見かけの大きさの変化はありません。

「平面」は画面外へ続く水面です。範囲を限定したい場合は「長方形」か「円形・楕円形」を選びます。「画像形状」は入力画像のアルファを使用します。「なし」で「画像形状」と波・水面色を使う場合は、入力画像とアルファを同じ投影で変形します。出力範囲外はクリップします。

## 描画範囲・制限

同じ時刻・シード・設定・入力では、逆シークや途中からの再生でも同じ結果を返します。幅・高さは各8,192ピクセル、総画素数は16,777,216が上限です。CPU で描画するため、高解像度では処理時間が増えます。

波・反射・泡は疑似表現です。専用の満ち引き・波打ち際、境界反射、渦、注ぎ込み、色の広がりは未実装です。画像ファイルの直接指定や、別オブジェクトの形状の直接参照は行いません。
