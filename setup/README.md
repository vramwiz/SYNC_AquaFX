# 水面演出

AviUtl2 用の水面生成・画像フィルタープラグイン「水面演出」（SYNC_AquaFX v0.5.0）です。Windows 64bit / AviUtl2 2.1.16 以降を対象とします。

素材なしで波・流れ・波紋のある水面を生成します。疑似反射・ハイライト・簡易泡、平面・長方形・楕円形、疑似3Dに対応します。

タイムラインへフィルタオブジェクトを置き、「SYNC」の「水面演出」を追加します。「背景あり」「海」を選び「設定」を押すと、下層に素材がなくても水面を生成します。

画像オブジェクトへ「水面演出」を追加して「ユーザー画像」を選ぶと、入力画像を変形します。透明部分には描画しません。「背景なし」は透明背景へハイライトと泡だけを描きます。

## プリセット

一番上の「プリセット」で用途を選び、その直下の「設定」を押すと、下の各パラメータへ初期値を一括反映します。選択だけでは値を変えず、反映後も個別に調整できます。表示モード・シードと「座標・変形」は維持します。

海、海岸、川、池、湖、水たまり、お風呂、プール、ラーメンスープ、味噌汁、牛乳、コーヒー、油、魔法液体の14種類があります。水系8種類は「魔法液体」の波・光沢を基準に調整しています。専用の満ち引き・波打ち際、境界反射、渦、色の広がりは今後追加します。

更新後はプリセットを選び直して「設定」を押してください。保存済みの以前の数値は、ボタンを押すまで維持します。

## 浮いている油

「油」は黄色い下地の上に、透けた黄金色の油膜が分かれて浮き、ゆっくり動くプリセットです。縁の陰と暖色の白い照りで膜の輪郭を出します。「表面の油」の「油膜の量」「油膜サイズ」「油膜光沢」「油膜色」で調整できます。量0で無効になり、水系プリセットへ「設定」で切り替えると油膜も0へ戻ります。

「液体色」は下地、「油膜色」は浮いた膜の色です。「背景なし」では油膜と光沢だけを透明背景に描き、「ユーザー画像」では入力アルファを保って重ねます。

ラーメンの写真などには、画像オブジェクトで「画像に油膜」を選び、プリセット「油」の「設定」を押します。元画像を動かさず、麺や具材の細部を残して油膜だけを重ねます。「円形・楕円形」と「座標・変形」でスープの位置へ合わせてください。具材の自動判別は行いません。透明度100・拡大率0・油膜の量0では元画像を維持します。

## 座標と傾斜

「座標・変形」で X/Y/Z、中心X/Y/Z、X/Y/Z軸回転、拡大率、縦横比、透明度を調整できます。Xは右、Yは下、Zは奥が正です。拡大率の初期値は100%、縦横比0、透明度0%です。

「3D傾斜角度」は -89～89度で、正値は上側が奥、負値は下側が奥になります。X軸回転は傾斜へ加算します。v0.3.0で傾斜方向を修正したため、以前の正値と見た目が変わります。

画像のアルファ形状も一緒に投影します。出力範囲外はクリップします。「平面」は無限に続くため、枠の位置や大きさを調整する場合は「長方形」や「円形・楕円形」を選んでください。

## インストール

1. AviUtl2 を終了します。
2. `SYNC_AquaFX.zip` を展開し、中の `SYNC_AquaFX` フォルダーを `C:\ProgramData\aviutl2\Plugin` へコピーします。
3. AviUtl2 を起動し、画像・フィルタオブジェクトへ「SYNC」の「水面演出」を追加します。

本体は `SYNC_AquaFX.auf2` の1つです。

更新時も同じ場所へ上書きします。アンインストール時は AviUtl2 を終了し、このプラグインのフォルダーを削除してください。

## 開発者向け: 配布 ZIP の作成

Win64 Release をビルドした後、`setup\make_release_zip.bat` を実行します。ParticleFX と同じく、ビルド済みの AUF2 を梱包し、カタログ末尾バージョンの XXH3-128 ハッシュを更新します。実行時のカレントフォルダーに依存せず、既定の入力は `%ProgramData%\aviutl2\Plugin\SYNC_AquaFX\SYNC_AquaFX.auf2` です。

この開発環境には ParticleFX と同じ `Win64\Dependencies\xxHash-0.8.4\xxhsum.exe` を配置済みで、引数なしで実行できます。新しい開発環境では同パスまたは PATH に用意するか、引数で指定してください。ツール自体は配布 ZIP に含めません。

```powershell
.\setup\make_release_zip.ps1 -XxhsumPath 'C:\Tools\xxhsum.exe'
.\setup\make_release_zip.bat -ReleaseDirectory 'V:\DelphiProg\SYNC_AquaFX\Win64\BuildCheck\Release'
```

出力は `setup\SYNC_AquaFX.zip` です。本体 AUF2、この README、LICENSE、THIRD_PARTY_NOTICES.md、ThirdParty/LICENSE.AviUtl2-SDK.txt の計5ファイルを収録します。

`SYNC_AquaFX.catalog.json` の最新バージョンは v0.5.0 です。JSON のリポジトリ・ZIP名・インストール先・全5ファイルの削除先を梱包時に検査します。ハッシュと ZIP は同じ AUF2 のコピーから生成し、失敗時は既存の ZIP とカタログを保ちます。GitHub の公開先は `vramwiz/SYNC_AquaFX` を想定した値のため、公開前に確認してください。スクリプトはネットワークへの公開を行いません。
